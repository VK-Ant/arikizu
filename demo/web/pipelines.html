Pipelines

YAML workflows that chain capabilities together. Run them manually or on a schedule.

WHAT IS A PIPELINE?

A pipeline is a .yaml file in the pipelines/ folder that lists stages. Each stage calls one capability (like vision.detect or reasoning.answer), passes its output to the next stage, and ends with actions (audit log, webhook, etc). Build one when you want several capabilities to run as a single unit, either on demand or on a schedule. See the full guide.
