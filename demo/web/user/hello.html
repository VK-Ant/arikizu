How this page works

Each button does one fetch against the Arikizu HTTP API:

const r = await fetch("/api/v1/call/CAP/NAME", {
  method: "POST",
  headers: {"content-type": "application/json"},
  body: JSON.stringify({ payload: { ...your inputs... } }),
});
const j = await r.json();

That is the entire integration surface. If you can write a fetch, you can build on Arikizu. See home for the full capability list.
